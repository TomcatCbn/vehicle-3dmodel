# 决策 19 — 开场尾灯特写后直接缓回整车

## 背景

当前开场在尾灯特写后继续执行车尾 → 左侧 → 右侧 → 车头特写 → 整车的长距离环绕。后段方向变化多，用户实际观看时感觉运镜过多、晃动明显，需要保留展示重点并简化收尾。

## 选项

### A. 尾灯特写后直接缓回整车（采用）

保留前段大弧转入和尾灯慢动作特写，后段使用一条连续平滑轨迹直接回到整车机位。删除绕车两侧和车头特写，保持一镜到底，晃动最小且改动集中。

### B. 尾灯特写后先后退再归位

先从车尾直线拉远，再转向整车机位。能补充空间展示，但多一次方向变化，仍可能产生轻微晃感。

### C. 尾灯特写后淡化切换到整车

取消后段相机位移，以短淡出、淡入完成切换。最稳定，但破坏当前一镜到底的连续感。

## 结论

采用 A。仅调整 `src/render/entrance.js` 的相机与注视点关键帧：在动画进度 0.42 的尾灯特写结束后，直接平滑插值到最终 `home` 机位和整车注视点，不再经过车侧或车头特写。

车辆行驶路线、车轮运动、尾灯慢动作时间映射、10 秒实际播放时长、最终机位及结束后的交互恢复均保持不变。继续使用同一相机和动画循环，不新增场景、效果或状态。

## 影响与验证

- 更新开场运镜测试：移除车侧和车头特写断言，增加尾灯后连续回位、相机不穿车身及最终取景不变的检查。
- 重新运行 `node scripts/export_entrance_poses.mjs`，同步 Blender 视频使用的 `public/models/entrance-poses.json`，保持应用与离线渲染位姿一致。
- 运行 `npm test`、`npm run build`，并在浏览器重播开场确认后段不再绕车晃动。
