# 17. 最新 main 上的尾部近照精修

## 背景

用户要求查看最新 main 并继续依据同一汽车之家细节目录完善模型。核对两个远端后，GitLab main 与当前 `200cd4e` 一致，GitHub main 较旧；从最新 main 创建 `feature/photo-detail-refinement`。已有半轴、差速器及其运动元数据保持保留。

四张尾部近照显示，原模型的圆杆雨刷、扰流板下摄像头、连续上部灯腔和水平导光带仍过于简化，尾门下缘的独立摄像头也未建模。

## 选项

1. 使用照片贴片：容易得到单一角度的效果，但不能支持旋转、尾门开合和拆解。
2. 新增独立总成与控制信号：这些小件没有独立车控需求，会增加接口维护负担。
3. 在现有总成内重建可见几何，沿用已有灯组角色、铰点和渲染流程。

## 结论

采用方案 3。后雨刷重建宽枢轴罩、渐细塑料臂和独立平胶条；上摄像头改为扰流板上缘楔形罩，尾门下缘补摄像头壳、镜头和压圈。尾灯导光带外角上扬并与侧面导光带接续，灯罩端点延伸到共享曲面边界以关闭接缝；下沿加入双排微棱纹，上部点阵灯腔限定在近照可见区域。雨刷和摄像头使用独立黑色塑料材质，减少近景软箱高光将其照成金属的观感。

保留 108 个总成、所有运动元数据和灯组角色数量；雨刷随后玻璃，上摄像头随扰流板，下摄像头随尾门，外侧尾灯继续固定。只按照片近似，不推断镜头光学参数或工程尺寸。

## 影响与验证方式

- 同步生成脚本、Blender 源文件、GLB 和 JSON；参考图存入隐藏集合，不导出图片贴片。
- 新增三个同源渲染视角，核对局部细节，并复查正后、后侧、尾门全开视图。
- 实际资产回归检查镜头无遮挡、雨刷断面、尾灯外角高差，以及半开、全开和复位时的尾门随动；沿用全量测试、构建和浏览器视觉核对。
- 参考来源及实际完成的检查记录在 `docs/references/aura-t6.md`。
