# 09 · 大弧转入、尾灯特写与车侧跟拍

## 背景

用户希望车辆从左上方沿大 L 弧线入场，多转一点露出车尾；缓慢停住的同时，镜头跟上并贴近尾灯，沿车侧向前移动，最终回到既有左前停放视角。本轮按桌面构图校准。

## 选项

1. 只让车辆转向、相机固定：路线清楚，但难以形成尾灯特写与沿侧面前移的运镜。
2. 把车辆行程与镜头行程分开采样，镜头局部轨迹跟随车辆坐标：能在车身仍减速时稳定对准尾灯，停车后继续沿车侧移动。
3. 完整环绕一圈：能展示各面，但增加与本次尾灯到车头路线无关的时长。

## 结论

采用选项 2。`src/render/entrance.js` 在既有唯一动画循环中采样，不创建独立场景或渲染循环。

- 根据用户草图依次采样大弧、回转和反向弯，使用向心 Catmull–Rom 曲线连接，旋转草图使最终切线与模型的 -X 停放方向一致。车头跟随路径切线；前段以固定机位观察车辆从远处沿大型右弧驶近，再衔接跟拍。
- 总时长 8.8 秒，车辆按弧长逐步减速，直到镜头结束时同时停稳。按曲率和轴距计算左右前轮不同的转角，并根据四轮各自的行程分别计算滚动相位；减速时点亮制动灯。这是近似运动学，未模拟悬架、轮胎滑移或完整车辆动力学。
- 固定开场结束后，镜头在车辆局部坐标中依次经过车尾远景、尾灯近景、车侧、左前车头，再拉远到默认视角。相机位置与观察目标使用非均匀时间的三次 Hermite 插值，避免镜头切段时跳变；近景是有意的局部取景。
- 最终恢复相机位置、观察目标、FOV=30、水平镜头、页面构图与车辆原点，保持现有拖拽、细节和行驶演示可以继续使用。
- 主光源和接触阴影跟随车身；同一 GLB、材质、canvas、renderer 与帧循环供整车、细节及行驶共用，不改变模型几何或元数据。

## 交互与影响

- 自动播放、重播、减少动态效果偏好共用同一入口；减少动态效果下不播放，运行时开启该偏好立即结束。
- 可跳过、Esc、拖拽、滚动、导航和切后台结束。捕获阶段先完成归位，再让 OrbitControls 或弹窗接管，避免保存未归位的相机。
- 整车控制区临时设置 `inert`，重播时焦点移到跳过按钮，结束后恢复。
- 自然播放停稳后调用既有车辆状态机关闭灯光、锁车并熄火；跳过不会执行该收尾。出场不发送起步或关门命令。车辆行驶、门/盖未关好或插枪时不重播；快照变成这些状态时结束。天窗可保持打开。
- 动画中的转向、制动与车辆运动为视觉演示，不代表真实车辆动力学或 MQTT / BLE 协议联调。

## 验证

测试覆盖开场机位固定、草图的右转大弧与反向弯、左右前轮不同转角、四轮不同滚动距离、减速及车与镜头同时停止、尾灯到侧面再到车头的镜头顺序、近景目标取景、相机不穿入闭合车身、终点精确复位及跳过/重播恢复。桌面采样 1280×900 与 1920×1080；实际浏览器核对完整路线与灯光。代表性截图位于 `output/entrance/rear-tour/`。
