# 14. 按官方细节图精修外观并开放分件数量

## 背景

现有模型已具备车控、开合和滚动拆解能力，但前舱仍是平面检修盖，轮组、充电口、主灯和底盘缺少官方细节图中的近景结构。用户指定汽车之家官方细节目录，要求逐张自主核对，不再限制 99 个总成，以提高建模精细度和近景质感为目标。

本轮检查目录全部 327 张图片。图片包含五种车漆和大量重复部位，因此采用“完整浏览、按部位去重、代表图归档”的核对方式，不把重复图片当作新增结构依据。

## 选项

1. 只调整材质和灯光：能改善截图观感，但无法纠正前舱不是深槽、充电口没有真实凹舱等几何差异。
2. 引入第三方精细整车模型：可能提升局部外观，却会破坏现有分件、铰点、运动元数据、车控联动和资产授权边界。
3. 沿用程序化 Blender 生成入口，按照官方细节图重建可见结构，并按功能需要增加独立总成：能保留现有 Three.js 管线和全部交互，同时让生成脚本、Blender、GLB 与 JSON 同步。

## 结论

选择方案 3。按部位完成以下修改：

- 将平面检修盖纠正为约 0.24 m 深的圆角前储物槽，保留 `front_service_bay` 运行时名称和拆解关系，显示名改为「前储物舱」。
- 在左后翼子板建立双接口凹舱和端子，新增独立 `charge_flap` 总成；部件总数由 99 调整为 100。充电盖随插枪信号向外翻转，不遮挡端子。
- 保留轮组五处真实开孔，增加气动肋、螺栓深凹座、内六角和气门嘴凹袋，采用官方图确认的胎侧品牌、型号和 `255/45 R20 101V` 规格。
- 增加主灯反射杯、阶梯饰圈、透镜压圈和光学棱线；底盘补分段护板、导流筋和示意连接结构。
- 新增充电口细节入口。该视角默认隔离凹舱和外盖，避免自动连接的充电枪挡住镜头；相机从左后侧观察，与充电口实际安装侧一致。
- 新增 `charge`、`underbody` 同源 Cycles 核对视角；主灯熄灭核对图临时关闭发光，只用于查看光学几何，不改变导出的灯控状态。

参考图片只进入 Blender 隐藏集合，不作为车身贴片，不复制第三方广告。前舱深度、充电盖铰点、底盘连接结构和不可见区域仍属照片近似或交互示意，不宣称原厂工程精度。

## 影响

- 修改 `scripts/build_aura_t6.py` 并同步生成 `models/aura-t6.blend`、`public/models/aura-t6.glb` 和 `public/models/aura-t6.json`；没有手工单改二进制资产。
- `src/render/vehicle.js` 增加充电盖联动，`src/render/inspection.js` 增加充电口选择、隔离和正确侧向取景，`src/main.js` 复用既有插枪命令，不另建冲突状态。
- 实际 GLB 回归覆盖深槽、轮组、双接口、充电盖、主灯和底盘；细节测试覆盖充电口默认隔离和左侧镜头方向。
- 最终 79/79 测试和生产构建通过。浏览器在 1280×900、390×844 核对前舱、充电口、拆解 100% 与复位 0%，错误日志为空。
- 分件数量不再作为固定目标；后续新增功能仍需保持运行时名称、extras、运动轴和拆解关系一致，不能只为增加数量而拆分部件。
