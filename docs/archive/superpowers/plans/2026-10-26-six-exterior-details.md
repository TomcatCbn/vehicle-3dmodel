# 六处外观细节校准

按用户最新六张近照继续已授权的照片重建。保留 VW 字形、黑色车型牌、99 个独立总成及电动功能。

1. 后视镜：曲面上下壳、透明灯条细棱、底部镜头和安装脚。
2. 车标：保持字形，细化黑色阶梯底座和下方摄像头眉边。
3. 车顶：贴合顶面的低矮感知外壳、拱形双层行李架。
4. 翼子板：楔形感知组件、凹槽、镜头与导流细棱。
5. 轮毂：五瓣黑色辐条、细切削银边、深色三角肋板、气门嘴与螺栓。
6. 轮胎：圆润胎肩、胎侧 HANKOOK / iON 字样及细纹；不标未确认的尺寸。
7. 独立查看后视镜、翼子板感知组件、车顶组件和轮胎，兼顾手机导航。

验证：先生成资产，再运行曲面/徽标自检、npm test、npm run build；核对同源 Cycles 渲染和浏览器桌面/窄屏、隔离恢复、开合与拆解复位。

照片仅供可见外观近似，不推断传感器内部类别或原厂工程参数。
