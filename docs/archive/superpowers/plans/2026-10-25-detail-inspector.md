# 独立三维细节查看

用户要求继续外观迭代，并指出无法单独看细节。沿用现有风格和同一个 WebGL 模型，增加全屏细节查看；本轮已完成的尾部外观随当前 GLB 一起展示。

- [x] 新建 `src/inspection.js`：前脸、车尾、主灯、车标、前轮组的实际网格选择；按包围盒和视口比例计算相机；隔离网格后可恢复可见性。
- [x] 增加原生 dialog，支持拖动、滚轮/双指缩放、放大缩小按钮、重置、仅看部件、Esc 与返回整车，管理焦点和页面滚动。
- [x] 在现有场景工具及拆解 HUD 添加入口；重用当前渲染器与画布，查看时临时组装，退出恢复页面位置、相机和状态。
- [x] 相机适配与可见性恢复使用实际 GLB 测试；浏览器验证桌面和手机的近景、缩放、退出及拆解页恢复。

不添加新依赖，不将三维查看替换为静态图片，不重做已认可的车标。

验证：`npm test` 14 项通过，`npm run build` 成功。桌面实际检查五个预设、旋转、滚轮放大、隔离切换、重置与 Esc/返回退出；390×844 视口检查轮组和车标的取景及操作布局。解锁、车窗 1% 在进出查看后保留，拆解 100% 时进出查看，页面 scrollTop 4192 和拆解进度均恢复。手机双指逻辑由 OrbitControls 提供，本轮未在实体手机上验证手势。隔离时按部件范围收紧阴影相机，解决轮胎近景的阴影锯齿。

截图：`output/playwright/inspector-rear.png`、`inspector-wheel.png`、`inspector-lamp.png`、`inspector-mobile.png`、`inspector-restored.png`。浏览器未出现运行错误；保留已有 RGBELoader 弃用提示。
