# 正前照片曲面对齐

用户补充白车正前实拍，要求继续校准灯带端部、机盖接缝和前舱盖板材质。本轮只调整这些可见表面，保留已认可的徽标和现有交互。

- [x] 灯带改为共用参数面：圆角端部、薄烟色罩面、贴合车角的法向深度；导光条改为扁平内嵌形状，移除圆管眉线和点状高光。
- [x] 降低机盖中部隆起、放宽纵向折线，前缘中段较平、外侧缓转；固定前沿与活动盖板采用同一曲面的法线，统一约 3 mm 的接缝。
- [x] 区分前舱检修盖与外围托盘：零金属度黑色塑料、不同粗糙度、细微颗粒；Blender 与浏览器各使用可重复生成的微表面，保留模型可拆解结构。
- [x] 用实际 GLB 验证塑料材质和微表面，用共享曲面自检验证灯带、机盖边界；回归开盖、撑杆、拆解和行驶拦截。
- [x] 重新生成并渲染正前/开盖/前侧对照，浏览器检查并记录截图；测试、构建通过后更新参考记录。

根因记录：加入法线自检后，旧甲板在 `r=0,u=±0.4/±0.8` 处法线朝下。首排使用前围的四次包角，后续行使用六次包角及另一套宽度映射，造成小幅折返。统一归一化前缘包角与宽度映射后，自检通过，并加入密集纵向单调性回归检查。

前侧近景另发现固定鼻部沿翼子板内边界也保留了缝隙；在 `r=.1` 处实测旧间隔 4.273 mm。调整为只在活动机盖侧边打开间隙，固定鼻部和后侧唇边处闭合，并取消描线圆管，使用实际开口与内部深色结构呈现接缝。

当前最终 GLB 为 92 个独立部件。22 项测试通过，覆盖检修盖/托盘不同粗糙度、微法线纹理非恒定及真实面板 UV、撑杆在三种开度下对齐、开盖不能起步、拆解与复位。生产构建、共享曲面及徽标自检通过。浏览器检查 1280×900 与 390×844 的前脸取景、开盖/闭盖和退出恢复。

最终浏览器回归：开盖时保持 0 km/h 并提示关闭，闭盖后可正常起步；拆解 100% 进出前舱，scrollTop 3992 和进度均恢复。错误日志为空。截图：`output/playwright/aura-front-photo-front-browser.png`、`aura-front-photo-quarter-browser.png`、`aura-front-photo-open-browser.png`、`aura-front-photo-mobile.png`。最终离线图：`aura-t6-detail-front-photo.png`（同一几何、白色车漆）、`aura-t6-detail-hood-quarter.png`。手机仅检查浏览器视口，实体设备手势及广告级车型精度不在此次验证范围。
