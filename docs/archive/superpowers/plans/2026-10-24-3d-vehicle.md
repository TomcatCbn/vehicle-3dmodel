# 3D 车辆与滚动拆解实现计划

目标：提供本地可运行的参数化车辆、车控操作和可逆滚动爆炸图。
架构：Three.js 车辆部件树负责展示，独立状态逻辑负责车控目标和实际变化；页面滚动映射拆解进度。无服务端，无协议连接。
技术栈：Vite、Three.js、原生 JavaScript/CSS、Node test。

- [x] 状态：先测试窗户逐渐运动、范围约束、未插枪拒绝充电、重置及可逆拆解插值；运行 `npm test`，完成最小实现。
- [x] 模型：`src/vehicle.js` 创建可分离车身板件、车窗、门、座椅、轮胎、轮毂、刹车盘、底盘、电池与动力总成。每件保存组装位置和拆解偏移。
- [x] 页面：`index.html`、`src/main.js`、`src/style.css` 实现展台、车控、颜色选择、观察视角、部件高亮、滚动拆解、重置、移动端布局和减少动态效果。
