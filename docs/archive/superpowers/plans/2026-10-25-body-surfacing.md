# AURA T6 车身曲面重建

本轮按用户明确要求优先改善外观。沿用激光雷达 A 版与第一款轮毂，保留独立车门、升降玻璃和拆解结构。

- [x] 统一曲面截面：侧面肩部、鼻部和尾部的上下收放；前后围与翼子板共享接边。
- [x] 侧窗下沿收回车身肩部；圆角侧窗、片状 A 柱和顶梁、曲面扰流板，减少管件拼装感。
- [x] 轮拱改为片状饰板，增加车门下部黑色包围与肩部曲率。
- [x] 前脸降低并后倾，灯组贴合鼻部曲面；尾部增加牌照凹陷、保险杠转折与包角。
- [x] 轮毂重建深度、切削面、开放轮辐和制动结构，增加胎面细节。
- [x] 核对侧视、正前、正后、三分之四及轮毂近景；运行截面连续性检查、实际 GLB 回归测试和构建，复核浏览器交互。

判定以实际三维画面的轮廓和反射连续性为准，测试通过不代表已经达到参考照片的造型精度。

本轮验证：截面检查通过；11 项测试通过；生产构建成功（仍有现有的主包超过 500 kB 提示）。实际浏览器核对开门、四窗 100%、拆解 100% 及复位；错误日志为空。检查 1280 × 900 和 390 × 844 视口，结束后恢复默认视口。

实际页面证据位于 `output/playwright/aura-t6-curves-browser.png`、`aura-t6-curves-rear-browser.png`、`aura-t6-curves-controls.png`、`aura-t6-curves-exploded.png`、`aura-t6-curves-mobile.png`。当前 Cycles 核对图为 `aura-t6-cycles-preview.png` 和 `aura-t6-detail-{front,rear,side,wheel}.png`。

剩余外观差距：前脸灯带与发动机盖的比例、尾部曲率转折以及部分车身反射仍与参考图不同。本轮交付为可交互的曲面改进版本，未达到广告图或原厂 CAD 的还原精度。
