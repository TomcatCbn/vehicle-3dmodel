# 前舱与机盖照片对齐

目标：按用户新增正面、前侧开盖照片，将现有整片前甲板拆成活动机盖、固定前沿和翼子板上肩，补充机盖内板与可见前舱，并能开合检查。

- [ ] 共享甲板/机盖参数曲面，保留前围接边，固定前沿与活动盖板留 3–4 mm 接缝。机盖铰点位于挡风玻璃前端。
- [ ] Blender 新增内侧冲压筋、隔音衬板、四个压片、锁钩、检修盖板、蓝色加注口、紧固件、密封圈、铰链及两根可伸缩撑杆。前灯带补镜片层与细分反射面，进气格栅改为扁平叶片。
- [ ] 车控增加机盖开合，状态逐步过渡；前舱细节预设可查看开盖结构。行驶前同时校验机盖已关拢。
- [ ] 先验证机盖绕真实铰点运动、撑杆两端对齐、行驶拦截及机盖状态渐变的失败测试，再实现并用新 GLB 验证。
- [ ] 重新生成 Blender/GLB，检查开/闭盖前脸渲染和浏览器近景、侧向遮挡、手机布局、拆解恢复、行驶入口。通过测试/构建后记录截图和准确性边界。

照片只支持可见结构的近似重建，不推断盖板下方动力总成，也不把前舱模拟成发动机舱或储物箱。
