# 前舱与机盖照片对齐

目标：按用户新增正面、前侧开盖照片，将现有整片前甲板拆成活动机盖、固定前沿和翼子板上肩，补充机盖内板与可见前舱，并能开合检查。

- [x] 共享甲板/机盖参数曲面，保留前围接边，固定前沿与活动盖板留 3–4 mm 接缝。机盖铰点位于挡风玻璃前端。
- [x] Blender 新增内侧冲压筋、隔音衬板、四个压片、锁钩、检修盖板、蓝色加注口、紧固件、密封圈、铰链及两根可伸缩撑杆。前灯带补镜片层与细分反射面，进气格栅改为扁平叶片。
- [x] 车控增加机盖开合，状态逐步过渡；前舱细节预设可查看开盖结构。行驶前同时校验机盖已关拢。
- [x] 先验证机盖绕真实铰点运动、撑杆两端对齐、行驶拦截及机盖状态渐变的失败测试，再实现并用新 GLB 验证。
- [x] 重新生成 Blender/GLB，检查开/闭盖前脸渲染和浏览器近景、侧向遮挡、手机布局、拆解恢复、行驶入口。通过测试/构建后记录截图和准确性边界。

照片只支持可见结构的近似重建，不推断盖板下方动力总成，也不把前舱模拟成发动机舱或储物箱。

2026-10-26 完成验证：实际 GLB 为 92 个部件，21 项测试、生产构建、共享曲面和徽标自检通过。机盖在闭合/半开/全开时，撑杆上端均贴合机盖连接点。浏览器检查 1280×900 和 390×844 取景、开关按钮及隔离查看；控制台底部与页面底栏不重叠。开盖时起步保持 0 km/h 并提示先关盖，关好后可重新起步。拆解 100% 进入前舱后返回，scrollTop 3992 和进度保持原位。当前浏览器错误日志为空。
