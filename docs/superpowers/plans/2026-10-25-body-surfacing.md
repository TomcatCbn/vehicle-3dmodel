# AURA T6 车身曲面重建

本轮按用户明确要求优先改善外观。沿用激光雷达 A 版与第一款轮毂，保留独立车门、升降玻璃和拆解结构。

- [ ] 统一曲面截面：侧面肩部、鼻部和尾部的上下收放；前后围与翼子板共享接边。
- [ ] 侧窗下沿收回车身肩部；圆角侧窗、片状 A 柱和顶梁、曲面扰流板，消除管件拼装感。
- [ ] 轮拱改为片状饰板，增加车门下部黑色包围与肩部曲率。
- [ ] 前脸降低并后倾，灯组贴合鼻部曲面；尾部增加牌照凹陷、保险杠转折与包角。
- [ ] 轮毂重建深度、切削面、开放轮辐和制动结构，增加胎面细节。
- [ ] 核对侧视、正前、正后、三分之四及轮毂近景；运行截面连续性检查、实际 GLB 回归测试和构建，复核浏览器交互。

判定以实际三维画面的轮廓和反射连续性为准，测试通过不代表已经达到参考照片的造型精度。
