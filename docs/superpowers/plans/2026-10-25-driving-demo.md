# 行驶演示实现计划

**目标：** 同一 T6 三维模型能起步、调速、停车，显示转动轮组与后退路面。

**方案：** 独立全屏原生 dialog 共用画布和相机；固定车身，由累计行程驱动路面和轮胎角度。保持现有车控、拆解与细节查看；不引入物理引擎或新依赖。

- [x] `src/drive-state.js` / `tests/driving.test.js`：0–100 km/h 目标速度，平滑加减速，按米累计行程；开门、插枪不能起步，停车后可再次起步。先测试失败再实现。
- [x] `src/vehicle.js` / `tests/model-asset.test.js`：实际 GLB 四个轮胎与四个轮毂绕原轮心旋转，轮轴和制动钳固定；关闭行驶恢复原朝向。
- [x] `src/driving.js`：道路标线与路边道钉按行程循环，全屏查看管理画布、相机、焦点和滚动恢复；起步、停车、速度滑块与三个相机预设。退出归零并暂停。
- [x] `src/main.js` / `src/studio.js` / `index.html` / `src/style.css`：实验室与拆解 HUD 提供入口，行驶中临时组装且冻结滚动相机；专用路面替换反射地台，布局适配手机。
- [x] 运行 `npm test`、`npm run build`；浏览器验证起步、调速、停车、重新起步、三个相机、退出恢复、细节查看与拆解共存、手机布局。记录截图并更新 README。

验证边界：属于直线视觉行驶演示，速度和行程为本地模拟，不含真实车辆动力学、转向、碰撞、能耗或 MQTT/BLE 控制。

验证结果：18 项测试通过，生产构建成功。浏览器实际观察 0→40→100 km/h、停车到 0 和再次起步；插枪与开门时维持 0 km/h 并显示提示；三个相机及 390×844 手机布局正常。行驶后轮毂可独立查看，拆解 100% 进出行驶后 scrollTop 4192 及进度恢复。截图保存为 `output/playwright/driving-front.png`、`driving-side.png`、`driving-rear.png`、`driving-mobile.png`。浏览器后台停车与实体手机手势未在本轮实机验证。
